Anthropic "sube" los límites de Claude Code un 25%, pero en la práctica es un recorte del 17%

Cejaloca · 1 de septiembre de 2026
inteligencia-artificial anthropic claude claude-code ia

Anthropic anunció que a partir del 14 de septiembre los límites semanales estándar de Claude Code van a subir un 25% de forma permanente para los planes Pro, Max, Team y Enterprise con asientos. Leído así, suena a buena noticia. El problema es que ese 25% no se suma a lo que tenés hoy: reemplaza un boost temporal del 50% que está activo desde hace meses, así que el resultado neto es 17% menos capacidad que la que usás actualmente.

La matemática detrás del "aumento"

Si el límite semanal original de Claude Code era 100 unidades, el boost temporal que está corriendo ahora lo llevó a 150. A partir del 14 de septiembre, ese número baja a 125. Es decir: vas a tener 25% más que antes de que arrancara la promo, pero un 17% menos que lo que tenés disponible hoy mismo (125 ÷ 150 = 0,833, un recorte del 16,7% que Anthropic redondea a 17%).

Cómo llegamos hasta acá

El 13 de mayo, Anthropic sorprendió a los desarrolladores con un boost temporal del 50% en los límites semanales de Claude Code. En vez de dejar que la promo venciera como estaba planeado originalmente, la compañía extendió la fecha límite cuatro veces distintas durante el verano boreal, manteniendo la capacidad inflada activa el tiempo suficiente como para que se sintiera como la nueva normalidad. Esa racha se corta el 13 de septiembre: al día siguiente entra en vigencia el nuevo límite permanente.

Qué dice Anthropic

La compañía explicó que la razón es la dificultad para asegurar suficiente cómputo como para sostener los límites más altos de forma permanente. En un principio publicaron el anuncio enmarcándolo solo como una suba, pero después de las críticas borraron el posteo original y publicaron una aclaración reconociendo el recorte directamente: "comparado con hoy, esto representa una reducción del 17% en los límites semanales de Claude Code". También prometieron que vienen "cambios interesantes" para que el uso se sienta como si estuvieras recibiendo más de Claude, con mejor visibilidad y control sobre tu consumo, aunque todavía no dieron detalles.

Qué significa esto si usás Claude Code

Para cualquiera que dependa de Claude Code todos los días —programadores, equipos que automatizan tareas, o cualquiera usando Cowork, ya que el consumo se comparte entre Claude Code, el chat y Cowork— conviene planificar el trabajo pesado antes del 13 de septiembre, mientras el boost del 50% sigue activo. Después de esa fecha, vale la pena prestarle atención al consumo semanal para no quedarte a mitad de una tarea larga. Anthropic aclaró que el uso no se traduce en una cantidad fija de prompts, porque varía según la duración de la conversación, el modelo elegido, las herramientas que se usan y el nivel de esfuerzo configurado.

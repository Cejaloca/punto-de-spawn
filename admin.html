☁️ Cloudflare Web Analytics

Sin configurar

Cómo obtener las credenciales:

  1. Account ID: Abrí dash.cloudflare.com, el ID aparece en la URL o en el sidebar derecho.
  2. Site Tag: Cloudflare → Web Analytics → tu sitio → en "Manage site" el Site Tag está en la URL.
  3. API Token: My Profile → API Tokens → Create Token → usa la plantilla "Read analytics and logs" o asigná permiso Account Analytics:Read.

🔍 Google Search Console

Sin configurar

Configurar OAuth (una sola vez):

  1. Andá a console.cloud.google.com.
  2. Creá un proyecto nuevo (ej: "PuntoDeSpawn Analytics").
  3. APIs → Habilitar → Google Search Console API → Habilitar.
  4. APIs → Habilitar → Google Analytics Data API → Habilitar (para la pestaña Comportamiento).
  5. Credentials → Create Credentials → OAuth Client ID → tipo: Web Application.
  6. En "Authorized JavaScript origins" agregá: https://puntodespawn.com.
  7. Copiá el Client ID y pegalo arriba.
